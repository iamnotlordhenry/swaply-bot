# Swaply Bot MVP

Рабочий Telegram-бот на Python для регистрации анкет Swaply.

## Что реализовано

- имя пользователя;
- до 3 рабочих городов;
- раздел «Что я могу»;
- типы: услуга, товар, реклама;
- поиск по короткому каталогу;
- выбор одного или нескольких городов либо «Любой город»;
- описание;
- опыт для услуг;
- отдельная ссылка на портфолио или соцсеть для каждого предложения;
- раздел «Что я хочу»;
- текст «О себе»;
- до 10 общих фотографий профиля;
- предпросмотр анкеты;
- сохранение и публикация анкеты в SQLite;
- просмотр своей анкеты и повторная регистрация.

## Запуск

1. Установите Python 3.11+.
2. Создайте бота через BotFather и получите токен.
3. Скопируйте `.env.example` в `.env`.
4. Вставьте токен в `BOT_TOKEN`.
5. Установите зависимости:

```bash
pip install -r requirements.txt
```

6. Запустите:

```bash
python main.py
```

## Примечание

Это готовая основа MVP регистрации и хранения профилей. Лайки, выдача анкет,
взаимный матч и открытие контактов можно добавлять следующим модулем, не меняя
структуру регистрации.


## Запуск на Railway

1. Загрузите содержимое этой папки в корень GitHub-репозитория.
2. В Railway выберите Deploy from GitHub repo.
3. Добавьте переменную `BOT_TOKEN`.
4. Запустите Deploy.

Стартовая команда уже задана в `railway.toml`: `python main.py`.

### Важно про тестовую базу

SQLite хранится внутри контейнера Railway. Для тестирования этого достаточно,
но при пересоздании контейнера данные могут исчезнуть. Для постоянной рабочей
версии следует перейти на PostgreSQL или подключить постоянный том.
